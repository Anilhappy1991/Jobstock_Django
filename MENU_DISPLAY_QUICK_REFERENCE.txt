REQUIREMENT:
- No user login           --> NO menu shown
- Employee login          --> Show HIRING MANAGER menu
- Hiring Manager login    --> Show HIRING MANAGER menu
- RPO Admin login         --> Show RPO ADMIN menu

========================================================================

IMPLEMENTATION:

1. Role Mapping (MenuValidationService):
   employee --> hiring_manager (same menu)
   hiring_manager --> hiring_manager
   rpo_admin --> rpo_admin

2. Template Check (hierarchical_menu.html):
   {% if user.is_authenticated %}
       <!-- Show menu -->
   {% endif %}

3. Service Layer (NavigationService):
   - Maps employee role to hiring_manager
   - Filters navigation by mapped role
   - Returns menu items based on role
