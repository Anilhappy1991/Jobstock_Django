📝 SETUP (30 minutes, one-time):

┌──────────────────────────────────────────────────────────────────┐
│  FOR FRONTEND DEVELOPER (REMOTE)                                 │
└──────────────────────────────────────────────────────────────────┘

📝 SETUP (15 minutes, one-time):

  1. INSTALL GIT:
     Download: https://git-scm.com

  2. CONFIGURE GIT:
     git config --global user.name "Your Name"
     git config --global user.email "your@email.com"

  3. CLONE REPOSITORY:
     git clone https://github.com/USERNAME/jobstock-frontend.git
     cd jobstock-frontend

  4. INSTALL EDITOR (optional):
     Download VS Code: https://code.visualstudio.com


💼 DAILY WORK (Super Simple!):

  Morning:
     git pull

  Work:
     • Edit files in templates/ folder (HTML)
     • Edit files in static/css/ folder (CSS)
     • Edit files in static/js/ folder (JavaScript)
     • Save files

  Evening:
     git add .
     git commit -m "Description of what you changed"
     git push

  Done:
     • Notify backend developer
     • "Hey, pushed homepage changes!"


┌──────────────────────────────────────────────────────────────────┐
│  WHAT FRONTEND DEV CAN EDIT                                      │
└──────────────────────────────────────────────────────────────────┘

  ✅ EDIT THESE:
     templates/pages/index.html        → Homepage

     templates/Base/footer.html        → Footer

     static/js/main.js                 → JavaScript
     static/img/                       → Images

  ❌ DON'T TOUCH:
     App/                              → Python code
     Jobstock/                         → Settings
     *.py files                        → Backend
     db.sqlite3                        → Database

  ⚠️  DON'T REMOVE:
     {% load static %}                 → Django template tags
     {% static 'path' %}               → Keep these!
     {{ variables }}                   → Don't delete!

┌──────────────────────────────────────────────────────────────────┐
│  TROUBLESHOOTING                                                 │
└──────────────────────────────────────────────────────────────────┘

  ❌ "Permission denied"
     → Add them as collaborator on GitHub

  ❌ "Need to pull first"
     → git pull
     → git push

  ❌ "Merge conflict"
     → Open conflicted file
     → Remove <<<< ==== >>>> markers
     → Keep correct version
     → git add filename
     → git commit -m "Fixed conflict"
     → git push

  ❌ Changes not showing
     → git pull (to get changes)
     → python manage.py runserver (to test)
     → Ctrl+F5 in browser (hard refresh)
